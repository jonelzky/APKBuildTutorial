STRUCTURE 2. Tamang Project Structure

~/MyApp_Final/ ├── app/src/main/ │ ├── AndroidManifest.xml <- package name dito! │ ├── java/com/myapp/app/ │ │ └── MainActivity.java <- package name DAPAT SAME! │ ├── res/values/ │ │ └── strings.xml │ └── assets/ │ └── index.html <- yung HTML mo! └── bin/ <- dito lalabas yung APK
⚠️ PINAKA-IMPORTANT: Yung package sa AndroidManifest.xml DAPAT SAME sa package sa MainActivity.java!
Manifest: package="com.bsrtsum.app" -> Java: package com.bsrtsum.app; -> MainActivity.java nasa folder .../com/bsrtsum/app/

Sample AndroidManifest.xml

<?xml version="1.0" encoding="utf-8"?> <manifest xmlns:android="http://schemas.android.com/apk/res/android" package="com.bsrtsum.app"> <uses-sdk android:minSdkVersion="21" android:targetSdkVersion="33" /> <uses-permission android:name="android.permission.INTERNET"/> <application android:label="@string/app_name" android:theme="@android:style/Theme.NoTitleBar"> <activity android:name=".MainActivity" android:exported="true"> <intent-filter><action android:name="android.intent.action.MAIN"/><category android:name="android.intent.category.LAUNCHER"/></intent-filter> </activity> </application> </manifest>

Sample MainActivity.java (WebView + File Upload Fix)

package com.bsrtsum.app; import android.app.Activity; import android.os.Bundle; import android.webkit.*; import android.content.Intent; import android.net.Uri; public class MainActivity extends Activity { WebView wv; ValueCallback<Uri[]> filePathCallback; final int FILE_REQ = 1; protected void onCreate(Bundle b){ super.onCreate(b); wv=new WebView(this); wv.setWebChromeClient(new WebChromeClient(){ public boolean onShowFileChooser(WebView view, ValueCallback<Uri[]> cb, FileChooserParams params){ filePathCallback=cb; Intent intent=new Intent(Intent.ACTION_GET_CONTENT); intent.addCategory(Intent.CATEGORY_OPENABLE); intent.setType("*/*"); String[] mimes={"application/pdf","text/plain","application/msword"}; intent.putExtra(Intent.EXTRA_MIME_TYPES, mimes); startActivityForResult(Intent.createChooser(intent,"Choose File"), FILE_REQ); return true; } }); wv.setWebViewClient(new WebViewClient()); wv.getSettings().setJavaScriptEnabled(true); wv.getSettings().setDomStorageEnabled(true); wv.getSettings().setAllowFileAccess(true); wv.loadUrl("file:///android_asset/index.html"); setContentView(wv); } protected void onActivityResult(int rc, int res, Intent data){ super.onActivityResult(rc,res,data); if(rc==FILE_REQ){ if(filePathCallback!=null){ Uri[] results=null; if(res==RESULT_OK && data!=null){ String d=data.getDataString(); if(d!=null) results=new Uri[]{Uri.parse(d)}; } filePathCallback.onReceiveValue(results); filePathCallback=null; } } } public void onBackPressed(){ if(wv!=null&&wv.canGoBack()) wv.goBack(); else super.onBackPressed(); } }
✅ Ito yung fix sa "Choose File not clickable" — yung naging problema natin sa BSRTSum! Kailangan onShowFileChooser!

BUILD 3. COMPLETE BUILD COMMANDS (Copy-Paste Lahat!)

    Step 1: aapt package - gawa R.java at unsigned APK na walang dex
    aapt package -f -m -J app/src/main/java -M app/src/main/AndroidManifest.xml -S app/src/main/res -A app/src/main/assets -I $ANDROID_JAR -F bin/MyApp-unsigned.apk
    -f force, -m make dirs, -J output R.java, -M manifest, -S res, -A assets, -I android.jar, -F output apk
    Step 2: javac - compile Java to .class
    javac -d bin -classpath $ANDROID_JAR -sourcepath app/src/main/java app/src/main/java/com/bsrtsum/app/*.java
    ⚠️ Dito madalas error! Dapat -d bin, hindi -d bin/classes.dex! At dapat may R.java na!
    Step 3: d8 - convert .class to classes.dex (MOST IMPORTANT FIX!)
    # MALI - ito yung dati nating error 8.3K APK! # $D8 --output bin/classes.dex bin/*.class <- MALI! wildcard hindi nag-eexpand sa Termux! # TAMA - ito yung fix natin! $D8 --output bin/ --lib $ANDROID_JAR $(find bin -name "*.class")
    ✅ FIX: --output bin/ (directory, hindi file!) + --lib $ANDROID_JAR + $(find ...) para makuha lahat ng class including R.class at R$* classes!
    Step 4: Add dex to APK
    cd bin aapt add MyApp-unsigned.apk classes.dex # check size - dapat 200K+ hindi 8K! ls -lh MyApp-unsigned.apk
    Step 5: Sign APK
    apksigner sign --min-sdk-version 21 --ks ~/.android/debug.keystore --ks-pass pass:android --key-pass pass:android --ks-key-alias androiddebugkey MyApp-unsigned.apk # output same file pero signed na! cp MyApp-unsigned.apk /storage/emulated/0/Download/MyApp.apk ls -lh /storage/emulated/0/Download/MyApp.apk # dapat 300K+ na, hindi 8K!

ERRORS 4. TROUBLESHOOT - Lahat ng Error na Na-encounter Natin!

❌ ERROR 1: BSRTSum keeps stopping / App keeps crashing
java.lang.RuntimeException: Unable to instantiate activity... Caused by: java.lang.ClassNotFoundException: Didn't find class "com.bsrtsum.app.MainActivity"
✅ FIX:
1. Check package name sa Manifest vs Java - DAPAT SAME!
Manifest package="com.bsrtsum.app" -> Java file dapat package com.bsrtsum.app;
2. Check kung nasa tamang folder: app/src/main/java/com/bsrtsum/app/MainActivity.java
3. Check kung kasama classes.dex sa APK! (aapt add ...)
4. Kung nag-install ka ng ibang app na same package (com.utilitycalc.app), magko-conflict! Uninstall muna:
pm uninstall com.bsrtsum.app --user 0 (check sa Termux)
❌ ERROR 2: APK is only 8.3K / 8KB (walang laman!)
-rw-rw---- 1 root everybody 8.3K ... MyApp.apk <- SOBRANG LIIT!
✅ FIX: Hindi na-add yung classes.dex!
Root cause:
- Wildcard *.class hindi nagwo-work sa Termux d8! Dapat $(find bin -name "*.class")
- Mali yung output: --output bin/classes.dex (file) dapat --output bin/ (directory!)
- Nakalimutan --lib $ANDROID_JAR

TAMA:
$D8 --output bin/ --lib $ANDROID_JAR $(find bin -name "*.class")
cd bin && aapt add MyApp-unsigned.apk classes.dex
❌ ERROR 3: R cannot be resolved / cannot find symbol R
error: package R does not exist error: cannot find symbol variable layout
✅ FIX: Hindi na-generate yung R.java!
1. Run muna aapt package -J app/src/main/java ... para mag-generate ng R.java
2. Check kung may res folder at strings.xml
3. Dapat after aapt, may app/src/main/java/com/bsrtsum/app/R.java na!
❌ ERROR 4: Choose File / Upload not clickable sa WebView
input type="file" hindi gumagana pag click
✅ FIX: Kailangan ng onShowFileChooser sa WebChromeClient!
Yung code na nasa STRUCTURE > MainActivity.java na may ValueCallback<Uri[]> at onActivityResult - yan ang fix na ginawa natin sa BSRTSum!
Without it, hindi talaga gagana file upload sa WebView!
❌ ERROR 5: Package conflict - overwrites other app
UtilityCalc at BSRTSum parehong com.utilitycalc.app - nagpapatong!
✅ FIX: Bawat app DAPAT UNIQUE package!
UtilityCalc = com.utilitycalc.app
BSRTSum = com.bsrtsum.app
TermuxFULL = com.chinheltermuxfull.app
Pad Pro = com.chinhelpadpro.app
Check: grep package app/src/main/AndroidManifest.xml
❌ ERROR 6: aapt: command not found / javac not found / d8 not found
bash: aapt: command not found
✅ FIX:
pkg install aapt apksigner openjdk-17 android-tools -y
Tapos set variables:
ANDROID_JAR=$HOME/android-sdk/platforms/android-33/android.jar
D8=$(find $HOME/android-sdk/build-tools -name d8 | head -n 1)
❌ ERROR 7: GitHub Pages 404 / index.html not found
✅ FIX:
1. Dapat may index.html sa root ng repo, hindi lang sa docs/
2. Enable Pages: GitHub repo > Settings > Pages > Source: main / root > Save
3. Wait 2 mins, check https://jonelzky.github.io/REPO/
4. Push via: git add index.html && git commit -m "add index" && git push
